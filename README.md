## 🚀 What I'm building

### Apontal

**Physical → Digital infrastructure for businesses.**

Apontal connects physical touchpoints such as **NFC cards, QR Codes, table displays, tags and printed materials** to dynamic digital destinations.

The platform is being designed around a simple idea:

> **The code stays. The destination changes.**

It evolves from digital presence to conversion, automation and business operations through features such as:

`Dynamic Links` · `NFC` · `QR Codes` · `Analytics` · `CRM` · `Automation` · `AI Agents` · `Dashboards`

The core platform is currently developed in a private repository.

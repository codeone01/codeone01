## 🚀 Atualmente construindo

### Apontal

**Infraestrutura Physical-to-Digital para negócios.**

A Apontal conecta pontos físicos como:

- NFC
- QR Codes
- cartões
- placas
- displays de mesa
- etiquetas
- materiais impressos

a destinos digitais dinâmicos, dados e processos de negócio.

A ideia central é simples:

> **O código fica. O destino muda.**

A plataforma evolui em quatro camadas:

```text
PRESENÇA
   ↓
CONVERSÃO
   ↓
AUTOMAÇÃO
   ↓
OPERAÇÃO
```

O ecossistema está sendo desenvolvido para incluir recursos como:

`Links dinâmicos` · `NFC` · `QR Codes` · `Analytics` · `CRM` · `Automações` · `Dashboards` · `IA` · `Agentes`

O **core da plataforma é proprietário e desenvolvido em repositório privado**.

### 🔍 AI Observability

Projeto experimental focado em monitoramento de agentes e aplicações de inteligência artificial.

A proposta é acompanhar como modelos e agentes se comportam em produção.

Exemplo de execução:

```text
Usuário
   ↓
Agent Router
   ↓
RAG
   ↓
Tool Calling
   ↓
LLM
   ↓
API externa
   ↓
Resposta
```

Métricas que podem ser acompanhadas:

```text
Latência
Tokens
Custo
Erros
Retries
Modelos utilizados
Ferramentas chamadas
Qualidade da resposta
```

O objetivo é estudar conceitos como:

- tracing
- logs
- avaliações
- comparação entre modelos
- custo por execução
- desempenho
- confiabilidade
- debugging de agentes
